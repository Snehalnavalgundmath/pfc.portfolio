01 / Project Overview

About the Project

The project studies a conventional rectifier and an improved rectifier using a boost PFC stage for EV charging applications.

↻

02 / Problem and Objectives

Problem Statement

Conventional rectifiers used in EV chargers can cause poor power factor, input-current distortion and fluctuations in the DC output voltage. Therefore, this project aims to design and simulate a single-phase boost Power Factor Correction (PFC) rectifier to improve input power quality and maintain a stable DC output voltage.

Project Objectives

✓ Develop a single-phase bridge rectifier with a boost PFC stage.
✓ Simulate the circuit and observe its electrical behaviour using PLECS.
✓ Implement suitable feedback control for DC output-voltage regulation.
✓ Compare the conventional rectifier and PFC rectifier using relevant performance measures.

04 / Project Workflow

Methodology

The project follows a step-by-step process from literature study to simulation and performance evaluation.

01

Literature Review

Study existing single-phase rectifier and boost PFC topologies, their operation and their performance in EV charging systems.

02

Circuit Modelling

Develop the bridge rectifier and boost converter model in PLECS using suitable initial component values.

03

Controller Design

Configure the feedback controller and PWM switching signals to regulate the output voltage.

04

Simulation

Run the circuit under selected operating conditions and record the input current, output voltage and other relevant waveforms.

05

Performance Evaluation

Evaluate the simulated results using power factor, input-current THD, output ripple and transient response where measurable.

06

Documentation

Compare the results, document the limitations and prepare the final project report and presentation.
